# Bundled Model Credit

Friendly Freya includes `freya_portuguese_water_dog.glb`, a binary glTF
conversion renamed from the `Dog` model in Quaternius's
[Cube World Kit](https://quaternius.com/packs/cubeworldkit.html), together with
its renamed `freya_portuguese_water_dog_Atlas.png` texture atlas.

the Windows release.
