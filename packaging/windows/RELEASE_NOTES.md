# Friendly Freya v0.1.2

This release adds the first complete neighborhood-control objective and
polishes the opening, controls, audio, dog encounters, and building interiors.

## Highlights

- Adds building claims, adjacency and scent-mark requirements, contested claim
  progress, Ryah's hand-drawn claim signs, territory tinting, and the win
  condition for controlling the full map.
- Adds menu audio settings and revised controls: Space pees or claims, R holds
  Freya's aggressive stance, and X uses the vomit ability.
- Improves the eat-first home tutorial, first-exit dog-possession sequence,
  alien navigation, and possessed-dog aggression and fear interactions.
- Fixes home and building cutaways, interior foundations, roof and wall
  visibility, character staging, and several tutorial camera compositions.
- Uses the selected extended title theme and keeps the authored bark library.
- Ships as a portable 64-bit Windows ZIP with no Godot installation required.

## Install

1. Download `Friendly-Freya-v0.1.2-Windows-x86_64.zip`.
2. Extract the complete ZIP.
3. Run `FriendlyFreya/FriendlyFreya.exe`.

Godot is not required. Windows may show a SmartScreen warning because this
prototype is not code signed.

The accompanying `.sha256` file can be used to verify the download.
