Friendly Freya - Standalone Windows Build

How to run:
1) Extract this folder on Windows.
2) Keep FriendlyFreya.exe and FriendlyFreya.pck in the same folder.
3) Double-click FriendlyFreya.exe.

No Godot installation is required.

Controls:
- WASD / Arrow keys: Move Freya
- Shift: Run
- Q / E: Rotate camera
- F: Eat nearby poop / pick up or drop stick
- Space: Vomit when meter is full
