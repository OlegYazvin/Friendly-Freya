# Dog Model Sources (Manual Import)

Drop dog models in this folder using the filenames below so Friendly Freya loads them automatically.

## Required filenames for auto-load

- Freya (preferred first match):
  - `freya_portuguese_water_dog.glb`
  - `freya_black_lab.glb`
  - `freya_dog.glb`

- NPC dogs (any/all):
  - `dog_labrador.glb`
  - `dog_golden.glb`
  - `dog_husky.glb`
  - `dog_neighbor_01.glb`
  - `dog_neighbor_02.glb`

## Recommended model sources

1. Labrador Retriever (free) - Sketchfab
   - https://sketchfab.com/3d-models/labrador-retriever-c6a671f8976f44f889f75f0d9f099ff5

3. Golden Retriever (free) - Sketchfab
   - https://sketchfab.com/3d-models/golden-retriever-f95f572f705440f7b01dc5477059f4fb

4. Husky (free) - Sketchfab
   - https://sketchfab.com/3d-models/husky-4386f89f4d7e46ce814383786754f632

5. Australian Shepherd (free) - Sketchfab
   - https://sketchfab.com/3d-models/australian-sheperd-89ca95f9a63147f7be83c460f22fb895

## Notes

- In Sketchfab downloads, prefer `.glb` or `.gltf` exports when available.
- Licenses vary by model (many are CC Attribution). Verify license and attribution requirements before shipping.
- If a model appears too large/small, update `model_scale` in `godot/scripts/main.gd` for that slot.
