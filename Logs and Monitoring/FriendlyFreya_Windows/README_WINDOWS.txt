Friendly Freya - Windows Package (Godot)

How to run:
1) Install Godot 4.x for Windows:
   https://godotengine.org/download/windows/
2) Unzip this package.
3) Double-click Run_Friendly_Freya_Windows.bat

Alternative run command (PowerShell):
  godot --path .\godot

Controls:
- WASD / Arrow keys: Move Freya
- Shift: Run
- Q / E: Rotate camera
- F: Eat nearby poop / pick up or drop stick
- Space: Vomit (when meter is full)

Notes:
- This package contains the Godot project source and assets.
- If the launcher says Godot is not found, add Godot to PATH or run Godot manually and open godot\project.godot.
